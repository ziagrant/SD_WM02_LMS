📋 Leave Management System (LMS)

A web-based Leave Management System developed for Chacks Creative Technology. The system allows employees to submit leave requests and enables HR managers to review applications, approve employee accounts, and generate reports.

📖 Project Overview

The Leave Management System was developed to simplify the process of managing employee leave requests. Employees can register, apply for leave, and monitor their requests, while HR managers can oversee employee registrations, approve leave requests, and view reports.
